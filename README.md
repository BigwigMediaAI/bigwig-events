# Bigwig Events

A modern event management and brand experience website for **Bigwig Events**, built to showcase the company's event services, portfolio, destinations, and creative capabilities. The platform presents Bigwig Events as an end-to-end event experience partner for corporate events, weddings, social celebrations, conferences, and destination experiences.

## 📌 Project Description

Bigwig Events is designed as a digital platform for presenting the company's event-management capabilities and helping potential clients discover relevant services and experiences.

The website brings together information about Bigwig Events, its services, portfolio, destinations, blogs, and event expertise in a visually engaging and responsive experience.

### Project Objectives

- Establish a strong digital presence for Bigwig Events.
- Showcase corporate and social event management capabilities.
- Present weddings, celebrations, conferences, and destination experiences.
- Highlight previous work and event portfolios.
- Communicate the company's end-to-end event management approach.
- Provide visitors with clear paths to explore services and plan an event.

## ⚙️ Setup & Installation

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone <repository-url>
cd bigwig-events
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

If the project uses environment variables, create a `.env.local` file in the project root and add the required values.

Example:

```env
NEXT_PUBLIC_API_BASE=
```

> Add only the variables actually required by the repository. Do not commit API keys or other sensitive credentials.

### 4. Start the Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

### 5. Create a Production Build

```bash
npm run build
```

### 6. Start the Production Server

```bash
npm start
```
